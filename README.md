# 航天基地 · 三角洲地图集

双击 **启动地图.cmd** 启动本机网页，需要 Python 3。也可以运行 `python serve.py`，终端会显示本次使用的地址。关闭服务窗口即可退出。静态网站的所有运行文件均在 `dist`，可以直接部署到支持 HTTPS 的静态服务器。

## 熟悉地图

- **环绕**　拖动旋转，右键拖动平移，滚轮缩放。点击地图标签或从索引搜索 13 个地标。
- **步行**　选择地标和起点高度，按“在此漫游”。用 WASD 或方向键行走，拖动环顾，Shift 加速。起点由模型中实际可站立的表面生成，菜单显示相对场景原点的米数。
- **自由飞行**　用 WASD 平移，E 和 Q 升降，可以穿过墙体观察层间关系。右上角的小地图同步显示位置和朝向。
- **平面地图**　使用与三维场景对齐的俯视底图。手机可以双指缩放，漫游时使用方向按钮。R 返回全图。

## 还原范围

场景以物理数据中的厘米为基准，转换为米。地形使用 59 个高度场的采样间距、有符号高度及各自的变换。场景共读取 18,848 条变换记录，包含地形与建筑等物体。远景采用简化网格，近景按分区加载全精度拓扑，共 4,727,865 个三角面。打包采用区域内 16 位位置量化，各轴的理论舍入误差最大约 1.2 毫米。这项精度描述的是文件转换。

地标中心与底图通过六个区域的建筑轮廓配准。水平位置约有米级偏差。俯视影像投影至外表面，立面与室内采用识图材质，水面为近似表现。原作的完整美术资产、活动设施状态和逐层实机测量尚缺，当前赛季的全图一致性未获验证。地标菜单里的不同高度可供探索，有些落点在楼旁平台。

## 数据和维护

- [航天基地物理场景及版本](https://github.com/QH190311/delta-force-3d-map/tree/fc335ace5e225c8dcae107b8e68cdee3aa61e572) 提供 `Physx/hangtianjidi.bin`。场景文件 SHA-256 为 `e1fc22f0ea0f7fc23a8227e897cd8e6f614158da5d20b74b654cc9850e762274`。
- [腾讯官方地图工具](https://df.qq.com/cp/a20240729directory/?map=htjd) 提供俯视影像和地标。[地标坐标](https://game.gtimg.cn/images/dfm/cp/a20240729directory/js/lib/map_htjd.js) 经平面配准换算为模型米坐标，公式为 `x=(mapX−668650)/100`，`z=(mapY+452830)/100`。
- 封面与六个地标的游戏画面对照取自[《三角洲行动》官方航天基地介绍](https://www.taptap.cn/moment/560580545478659238)。
- `tools/prepare.cjs` 可根据上述固定版本的场景重建网格。使用 Node.js，将源场景路径及 meshoptimizer 0.22.0 的 meshopt_simplifier.js 的绝对路径作为两个参数传入。随后运行 `node tools/landings.cjs` 更新步行落点。运行网站时使用预生成数据。
- 浏览器渲染使用 Three.js 0.160.1，碰撞查询使用 three-mesh-bvh 0.7.4。两者的许可证附于 `dist/vendor`。
