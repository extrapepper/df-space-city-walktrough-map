# 航天基地 · 三角洲地图集

[打开网页版地图](https://extrapepper.github.io/df-space-city-walktrough-map/)

双击 **启动地图.cmd** 启动本机网页，需要 Python 3。也可以运行 `python serve.py`，终端会显示本次使用的地址。关闭服务窗口即可退出。静态网站的所有运行文件均在 `dist`，可以直接部署到支持 HTTPS 的静态服务器。

## GitHub Pages 部署

仓库自带可部署的静态文件。Node.js 20 或以上运行 `node tools/build.cjs` 校验网页脚本、地图分区、楼层和贴图。GitHub Actions 在推送到 `main` 时校验并将 `dist/` 发布到 Pages，拉取请求运行相同的构建校验。Fork 后可在 Settings → Pages → Build and deployment 选择 GitHub Actions，再运行 Build and deploy atlas。网页资源使用相对路径，支持仓库名子路径。

## 熟悉地图

- **环绕**　拖动旋转，右键拖动平移，滚轮缩放。点击地图标签或从索引搜索 14 个地标。
- **步行**　选择地标和起点高度，按“在此漫游”。用 WASD 或方向键行走，移动鼠标环顾，Shift 奔跑，空格跳跃。Esc 释放鼠标，点击场景可重新接管视角。起点由模型中实际可站立的表面生成，菜单显示相对场景原点的米数。
- **自由飞行**　用 WASD 平移，E 和 Q 升降，可以穿过墙体观察层间关系。右上角的小地图同步显示位置和朝向。
- **室内看窗景**　从中控区的“南侧斜窗”看向中控桥，或在宿舍区选择“弧窗客房”。总裁室新增“雕塑前厅”，在这个起点可以对照官方蝶变赛季的雕塑近照。
- **按游戏画面找路**　在宿舍区、中控区、中控桥、工业区、发射区、水平试车场、码头区或总裁室打开“查看游戏画面”，点击“从这个视角自由飞行”。相机会移到画面的拍摄位置，可以继续向建筑入口飞行。
- **码头与水域**　从码头区的东侧上层、东侧中层或西侧下层进入建筑。从“码头前水面”出发可以直接游泳。用 WASD 游动，Q 下潜，E 上浮。触屏在水中会显示升降按钮。
- **实时大地图**　步行、游泳或飞行时按 M 或点击小地图。箭头同步显示位置和朝向，展开时仍可移动。支持缩放、平移和定位，再按 M 返回原视角。
- **平面地图**　使用与三维场景对齐的俯视底图。手机可以双指缩放，漫游时使用方向按钮。R 返回全图。
- **室内全景**　选中蓝室、黑室、浮力室、离心机室或总裁室后，点击“查看室内全景”，选择房间或楼梯间。90 个取景点通过三角洲工坊的分享页联网加载。关闭窗口后会回到原先的三维视角。

## 还原范围

场景以物理数据中的厘米为基准，转换为米。地形使用 59 个高度场的采样间距、有符号高度及各自的变换。场景共读取 18,848 条变换记录，包含地形与建筑等物体。远景采用简化网格，近景按分区加载全精度拓扑，共 4,727,865 个三角面。打包采用区域内 16 位位置量化，各轴的理论舍入误差最大约 1.2 毫米。这项精度描述的是文件转换。

中控楼南立面恢复了 18 块斜窗。五个宿舍楼实例共用同一弧窗模型，按实景核对的两组窗面套用到该模型的五处变换。玻璃在场景内取透明材质，仍参加步行碰撞。

物理场景同时保存了部分道具的粗碰撞外壳和细模型。构建工具按已核对的模型组合、记录位置和包围盒，为 1,957 个外壳单独标记显示方式。近景绘制对应的细模型，玩家仍受原碰撞限制。前厅雕塑公开的细模型含 716 个三角面，已按蝶变赛季画面中的刃尖和底座配准局部金属表面。

地标中心与底图通过六个区域的建筑轮廓配准。水平位置约有米级偏差。4096 × 4096 的俯视影像由 256 张官方原生四级瓦片拼接，覆盖范围约 1.31 千米见方。

七个地标采用局部实景投影，包括宿舍楼外墙、中控楼、中控桥两侧、工业区 B1 和 B2 厂房、发射台及相邻储罐、水平试车场分区墙和码头临水立面。相机由游戏画面中的建筑控制点与模型边缘拟合。投影使用同一网格渲染的深度和置信度遮罩，只覆盖从该拍摄视角可见的表面。树冠、烟雾、未拍到的背面以及多数室内继续使用识图材质。

官方 2.0 码头画面、俯视图和模型中的折线岸壁、东侧楼、西侧楼及连桥对应。三处码头起点分别用地图工具里的官方高度定位。将官方高度从厘米换算为米后加 190，与三处模型楼面的差值均小于 0.05 米。总裁室的默认起点也通过附近官方电脑机箱的高度校准，落在 −8.03 米的办公室楼面。角色起点稍微移到附近有净空的楼板。水位依码头画面估算为相对模型原点 −40.5 米，水域从外港在半米网格上沿连通水面求出，桥下可以通行。

原作的完整美术资产、活动设施状态和逐层实机测量尚缺。总裁室通道、浮力室动态注水和游戏中的具体上岸交互尚待核验。室内全景取景于 2025 年。建筑和陆地起点取自可站立表面，部分落点在楼旁平台。[官方版本介绍](https://www.playdeltaforce.com/season08/en/)

## 数据和维护

- [航天基地物理场景及版本](https://github.com/QH190311/delta-force-3d-map/tree/fc335ace5e225c8dcae107b8e68cdee3aa61e572) 提供 `Physx/hangtianjidi.bin`。场景文件 SHA-256 为 `e1fc22f0ea0f7fc23a8227e897cd8e6f614158da5d20b74b654cc9850e762274`。
- [腾讯官方地图工具](https://df.qq.com/cp/a20240729directory/?map=htjd) 提供俯视影像和地标。[地标坐标](https://game.gtimg.cn/images/dfm/cp/a20240729directory/js/lib/map_htjd.js) 经平面配准换算为模型米坐标，公式为 `x=(mapX−668650)/100`，`z=(mapY+452830)/100`。
- 封面、总裁室与其他地标的游戏画面对照取自[《三角洲行动》官方航天基地介绍](https://www.taptap.cn/moment/560580545478659238)。
- 码头画面来自[官方蝶变赛季介绍](https://www.playdeltaforce.com/season08/en/)。地图工具中的码头点位用于校验楼层，码头区标记位于东侧楼。
- 室内取景点按作者的分享标识定位，网页保留原站的全景导航和署名。[三角洲工坊航天基地全景](https://zzzmap.com/?map_type=htjd)
- `tools/prepare.cjs` 可根据上述固定版本的场景重建网格。使用 Node.js，将源场景路径及 meshoptimizer 0.22.0 的 meshopt_simplifier.js 的绝对路径作为两个参数传入。随后依次运行 `node tools/water.cjs` 和 `node tools/landings.cjs` 更新水域与漫游落点。运行网站时使用预生成数据。
- 浏览器渲染使用 Three.js 0.160.1，碰撞查询使用 three-mesh-bvh 0.7.4。两者的许可证附于 `dist/vendor`。

近景颜色与法线贴图取自 Poly Haven 的 CC0 扫描素材。按游戏参考画面调整尺度和配色。
